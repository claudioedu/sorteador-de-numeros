# Sorteador de Números

Aplicação web para sortear números inteiros. Você escolhe a quantidade, o intervalo e se os números podem se repetir.

## Prévia

![Tela inicial do Sorteador de Números no tema preto](assets/preview.png)

## Funcionalidades

- Sorteia números entre os valores mínimo e máximo, incluindo os dois limites.
- Permite evitar números repetidos.
- Exibe os resultados um a um e permite voltar ao formulário para sortear novamente.
- Oferece três temas: preto, azul-escuro e branco.

## Tecnologias

- **HTML** para estruturar o formulário e a área de resultados.
- **CSS** para o layout responsivo, os temas e as animações.
- **JavaScript** para sortear os números, exibir os resultados e trocar o tema.

## Como executar

Clone o repositório com Git e entre na pasta:

```bash
git clone https://github.com/claudioedu/sorteador-de-numeros.git
cd sorteador-de-numeros
```

Abra o arquivo `index.html` no navegador. No PowerShell, use:

```powershell
Invoke-Item .\index.html
```

Se tiver o Node.js instalado, você também pode verificar a sintaxe do JavaScript:

```bash
node --check script.js
```
